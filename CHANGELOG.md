# Changelog

## 0.3.0
- Removed the bundled Hugo Preview module, its routes, listeners, frontend, and compiled assets.
- Fixed the app navigation to open Reidel CRM Hub instead of Hugo Preview.
- Removed Hugo-only validation from the shared CRM project folder picker.
- Retained the standalone CRM integrations and existing CRM data model.
- Hugo Preview is now developed separately as `hugopreview_nc_app`.

## 0.2.2
- Support limited to Nextcloud 34 and 35 (the two most recent stable major versions).
- Declared compatibility narrowed accordingly.

## 0.2.1
- Initial public release.
